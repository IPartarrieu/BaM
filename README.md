# Tatami

App personal (PWA) para seguir el entrenamiento de gimnasio orientado a BJJ. https://ipartarrieu.github.io/Tatami/

- Pregunta cuánto tiempo hay (sugerido según el clima del día, Open-Meteo) y qué grupo muscular toca.
- Arma la rutina: calentamiento 5 min → ejercicios (series × reps × kg) → abdominales con disco (opcional) → elongar 5 min.
- Timer de descanso al marcar cada serie. Meta semanal de 3 sesiones, grupos pendientes, nivel por grupo, evolución de cargas y logros.
- Datos solo en el teléfono (localStorage); respaldo JSON desde la pestaña Avance.

Pruebas: `node tests/logic.test.mjs`
